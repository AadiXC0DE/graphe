# IPC inventory: every channel, its scope, its target and its owner

Phase 5.4's audit. One row per channel in `CHANNEL` (`src/lib/ipc.ts`), with what the call
names, where the main process turns that into a folder, a session or a process, whether it
changes anything, and what its answer belongs to. The count phase 5's "zero unqualified
mutation callers" is measured against is at the end.

## How to read a row

| Column | Meaning |
| --- | --- |
| channel | the wire name, in `CHANNEL` declaration order |
| scope | the narrowest thing the handler actually resolves to: `none` (no project at all), `project`, `conversation`, or `workspace` — one folder: a chat's own copy, a named child repo, or the folder the workspace registry wrote down |
| target | what the caller names: the trailing `Where` (`{project, conversation, repo}`), a positional id or path, or nothing |
| resolved | the expression in `electron/main.ts` that turns that into a folder, a session or a process. Line numbers are from the working tree this was written in and drift; the expressions do not. This copy is against `electron/main.ts` at blob `c9ff7865`, `src/App.tsx` at `29a3679c`, `src/lib/ipc.ts` at `e156634f` and `electron/preload.ts` at `7d8746df`. |
| mut. | `yes` when the handler changes something outside the value it returns: files, git, a process, a live session, a stored preference, or the shell's own state. Reading is `no`. A scratch file under `tmpdir()` that is removed again is not a change |
| owner | what the answer is about: `project`, `conversation`, `workspace`, `run`, `process`, `app` |
| callers | every call site under `src/**` (`src/lib/bridge.ts` is the wrapper, not a caller), at the revision this was written in. `+` names the target; `·` is a call with no target to name (app-wide, process, or read-only). A push row has none at all: the window subscribes with `bridge.on…(...)`, which is not a call of the channel. **`!`** marked an unqualified mutation caller and **`~`** a mutation whose channel had no target parameter at all — the two kinds phase 5 drove to zero, so no row carries either now |

The 18 shell-to-window pushes (`event`, `events`, `browserFrame`, `fromMenu`, ...) are asked for
by nothing: the shell sends them, so they have no handler and no caller. They are listed where
they sit in `CHANNEL`, marked `push`.

## The shape of the surface

- **211 channels**: **192** the window asks for, **19** the shell pushes.
- By scope, over the 192 asked for: **53 app-wide**, **61 project**, **38 conversation**, **40 workspace**.
- **133** mutate, **78** only read.
- **215 call sites** under `src/**` across 176 channels: **138** name a target, **70** have none to name. The other 34 channels are called from nowhere.

Counted by reading `CHANNEL` for the names and scanning every `.ts`/`.tsx` under `src/` for
`bridge.<name>(`; the method is in "The count".

## Unqualified mutation callers (phase 5.4's criterion)

A mutation caller is **unqualified** when the handler can resolve a target — an open project,
a conversation, a folder — and the caller names nothing, so the call lands on whatever is in
front. **None remain.** The 24 this inventory found were driven to zero by giving each call a
target, not by making the shell guess better for an unnamed one:

- **13 channels, 20 call sites.** Each call now builds a `Where` from the conversation, repo or
  workspace the press came from and passes it: `changesDrop`, `connectedSave`, `keepVersion`,
  `openInEditor`, `openSkillFile`, `revealFolder`, `shareReview`, `trustCarried`, and the
  model/advisor channels `selectModel`, `selectAdvisor`, `setAdvisorGate`, `setAdvisorThinking`
  and `setThinking`. Counting them again turned up two more `connectedSave` sites the first
  pass missed — the connected panel's connect and disconnect buttons — so 18 are 20 today.
- **4 channels had no target to give**: `pageAt`, `pageHidden`, `watchStart`, `watchStop` —
  one native page view and one watcher, shared by the whole window. Each now takes a
  **required** `where: Where` in `GrapheApi` (`src/lib/ipc.ts:2035`, `:2043`, `:2047`, `:2050`),
  `electron/preload.ts` forwards it (`named(where)`), and each handler refuses a call that
  does not name the page's own project
  (`pageNamed(whereIn(args))` at 12083, answering `NOT_THIS_PAGE`). Their 6 call sites are
  7 today, all in `src/hooks/usePreview.ts`.

Both halves show in the callers column below: no row carries **`!`** or **`~`** any more. What
is left uncounted is the table after this one.
