**A chat works in your project folder, and nothing copies your project behind your back.** Every conversation past the first used to be given a copy of the project to work in, made the moment you pressed New. That is a surprise twice over: the folder on screen stops being the folder the chat is writing to, and a copy that could not be made quietly fell back to writing in your project instead. A new chat now works in the folder you selected. If you want a chat somewhere of its own, press **New worktree**: it shows the folder it would make, the commit it would start from, and which of your uncommitted changes would not come with it, before anything exists. The card remembers which gitignored files you chose to bring into copies of this project, and installing the dependencies is its own press with its own state, rather than something that quietly happens or quietly does not.

**Looking at a chat no longer writes to your files.** Opening an isolated conversation used to carry its work into your project folder so that the two matched. Merging is now a press, and opening a chat is only looking.

**Merging says which copy and which folder.** The press reads **Merge worktree <name> into <project>**, and if the folder it would land in has work of its own, it refuses and names the files that are in the way rather than asking you to go looking.

**Closing a chat is looking away, not stopping it.** The x on a tab puts the view down and touches nothing: a chat with a turn still running keeps running, stays in the list saying it is still working, and has a **Stop** of its own. Ending the turn is that press, not the x.

**A chat picked up after the app stopped says what happened.** If Graphe goes away in the middle of a run, the next launch says so over that conversation, with when it was, and starts nothing again. Your words and the partial reply are where you left them.

**One chat writes at a time.** Two conversations can work in the same folder; they cannot write it at the same moment. A second send waits its turn, says so in the line above the composer - **Queued for this workspace**, naming the chat it is waiting on - and can be taken back, which actually cancels the wait now rather than leaving the words on screen.

**Continue, Fork, Archive.** A finished chat can be continued in a new one: a fresh conversation in the same workspace, opening with a short editable note about what was being made, where it got to and which files it touched - written from the conversation, not invented by a model, and put in the box as a draft so you can change it before sending. **Fork** makes a second conversation with the same history, and **Fork here** puts that under a finished exchange so it starts from a place you chose; it says plainly that the files are shared, because they are, and it waits rather than copying a turn that is still being written. **Archive** takes a chat out of the list and leaves everything else alone.

**A project can share something with every chat.** The sidebar keeps a **Project context** list - the brief, the style guide, whatever every chat in this folder should be given. It reaches the turn labelled as shared with the project rather than as something said in this chat, and it only grows when you share something with it.

**What you attach is kept, and kept once.** An accepted attachment is stored under the app's data folder by what is in it, so a retry, a reload, and the same picture sent from two conversations are one copy on disk rather than several.

**A terminal, in the folder you are looking at.** The Commands drawer switches between the run log and a real shell in the current workspace. It says in its header that it is yours and that the agent is not watching it, because that is true: nothing typed there goes through the permission rules.

**Add-ons can ask you things.** An installed extension that wants a choice, a confirmation, a line of text or a paragraph now gets a real dialog with its own words in it, and cancelling means cancelled rather than silently answered by the app. Anything an add-on asks for that only exists in a terminal says so out loud instead of pretending to work.

**Add-ons say what they are doing.** The Extensions screen has one row per add-on in one of eight states - discovered, needs trust, installed, active here, activation pending, disabled, incompatible, failed - each decided from what is on this computer and what your open chats actually loaded, rather than from a guess. A command an add-on registers is offered in the composer's `/` picker and runs as a command instead of being sent to the model as a sentence. If npm is not on this Mac, the screen says so, offers the page that installs Node, and offers `brew install node` only where there is a Homebrew to run it with.

**Checkpoints stopped touching your work.** Automatic save points used to stage everything in your repository and commit on your branch. They are now kept in Graphe's own place (`refs/graphe/checkpoints`), and your index, HEAD, branch and hooks are left exactly as they were - including a file you had half staged.

**A decision about a review is checked against what you were looking at.** If a file changes under a review between the moment it was read and the moment you answer, the answer is refused and the review is read again, rather than being carried out against bytes nobody agreed to.

**This Mac's missing pieces are said at the top.** If git or npm is not on the path, Graphe says so on the window rather than failing somewhere later, and the git presses stay out of the way until git is there.

**Deleting a chat keeps it, and there is a way back.** A deleted conversation is moved to `trash-conversations` inside the app's data folder with the time it went, rather than being destroyed. Settings has it under **Deleted conversations** on the Storage page: each kept conversation with its name, when it went and what it is taking, a **Restore** on its own row, and one press - **Empty selected** - that throws away only the ones you ticked. Nothing empties on its own, and the line above the list is the app's own sentence rather than a second copy of it: "Nothing in the trash is deleted on its own. It stays until you empty it."

**What was removed.** The design hub, the project style-sheet panel, and the automatic design-audit panels (legibility, drift, responsive, motion) are gone, along with the built-in tool that called itself `lsp` while only searching text. Text search is still there and is now called `search_symbols_text`, and an installed language server still gets its own tools. Live mirror - carrying every finished turn's files into your folder as the chat worked - is gone as well; the setting is remembered but nothing acts on it.

**Your existing chats are kept.** On the first launch of this version Graphe reads the copies and the conversations older versions left behind, writes down which folder each conversation works in, and copies the index files aside as `.bak` before touching anything. No folder is moved, renamed or deleted. A conversation whose copy is missing opens as unavailable rather than silently working in your project folder; a folder that is not the checkout it was is marked as needing attention instead of being adopted.

**Stability fixes.** Copy feedback no longer overlaps Fork here, the Work table headings have their own room, and growing conversations no longer accumulate phantom space below the last reply. Saved conversations reopen their original transcripts, deleting a chat removes its open views, queued sends release the workspace when finished, and migration preserves concurrent registry updates. Landing reviewed files keeps uncommitted work and ignored notes recoverable instead of deleting their checkout.

**Install**

Requires macOS 13 Ventura or later, on Apple Silicon or Intel.

```
brew tap AadiXC0DE/tap
brew install --cask graphe
```

Already have it: `brew upgrade --cask graphe`.

**Known limitations**

- An add-on install cannot be cancelled once it has started: the app says so on the screen instead of offering a Stop that cannot work. Ending an install needs the app to run npm itself, which is not in this version.
- Figma following, the variations screens and the recorded-evidence reel are still in this build. They are on the way out, and each is waiting on a way to export what it holds.
- The terminal needs a build that carries its helper. Both bundles of this version do, and one that does not says so instead of half-working.
- Pi is pinned to 0.85.1. Experimental child-process runtimes remain test-only; downloaded builds use the established in-process runtime.
- macOS builds are ad-hoc signed, not notarized. macOS may require approval in Privacy & Security on first launch.
