What you actually get

The whole agent. Not a chat box with tools bolted on.

pi is a serious coding harness and deliberately ships without sub-agents or plan mode. Graphe is what it becomes with both, plus everything else an interface makes possible.

01

It works in parallel, and it keeps working

Send three helpers into a codebase at once — reviewer, researcher, builder — each its own process with its own context. Run conversations side by side, each in its own checkout. Set a job going and close the window: it carries on, and you come back to a board of what finished, what's waiting, and what it cost.

02

It reads your design system first

Colours, spacing and type are read as a spec before a file is touched, so the work lands inside your system instead of on top of it. Figma frames come in as pictures and variables as tokens. Every change is checked at phone, desktop and wide, and anything that drifted from your own styles is named out loud.

03

You can see the bill before it lands

pi does real work to keep a prompt cacheable — one stable session, cache points where the provider needs them, every read and write recorded. Graphe puts the result on screen: how much of each turn came back from cache, what the sitting cost in your own currency, an estimate before a big job, and a ceiling that ends it.

How a sitting goes

Open a folder. Ask for something.
Watch it happen.

  1. 01

    Point it at a project

    No config file, no setup wizard. Open a folder and it is a project — recent ones sit on a shelf with what each cost you last time.

  2. 02

    Say what you want, however you have it

    Type it, paste a screenshot of it, or drop in a Figma frame. Speak it if your hands are busy. There is no syntax to learn.

  3. 03

    Big jobs come back as a plan

    A numbered plan, an estimate of what it will cost, and a wait for “Go ahead”. Small jobs just get done.

  4. 04

    It works where you can see it

    The file tree marks what changed. The rail names what it is doing right now, what it looked up, and what it has made so far.

  5. 05

    You look, then you decide

    Before and after, at phone, desktop and wide. Let it in, or set it aside — setting aside keeps the work reachable rather than throwing it away.

  6. 06

    Hand it to your team

    A write-up with the before-and-after pictures in it, a properly named line of work, and a request ready for whoever reviews. Or a page of what changed for somebody who is not a developer at all.

The foundation

Everything pi gives you.
Everything a terminal can't.

pi is a serious coding harness: any provider, any model, real extensions, and prompt caching engineered properly rather than hoped for. It ships deliberately without sub-agents or plan mode, and it ships in a terminal.

Graphe is everything around it — sub-agents and plan mode among them, plus the window, the guard, the version history, the design panel, the memory, the money and the handover. One module owns every pi import, so an upgrade breaks one file rather than fifty.

  • 3,000+ tests on every change
  • MIT licensed, all of it readable
  • Any provider, your own key
  • Local memory and embeddings, offline

pi gives you

  • Sub-agents, several at once
  • Plan mode, with what it will cost
  • A window: projects, tabs, rails, two themes
  • Your design system, read as a spec
  • Version history, with a picture of each change
  • A guard that asks in plain words
  • Background jobs, schedules and servers
  • Code review with a verdict, and the handover
  • Memory between sittings, kept on your machine
  • The money, on screen, in your own currency

Nothing leaves this computer.

Your code, your keys and your pictures stay on the machine. Exactly one feature in the whole app sends anything anywhere, it says so before it does, and it refuses outright if a private key is written into what would be sent.
